# VividCart — eCommerce Dashboard

A modern, responsive admin dashboard for an eCommerce store. Built with React, TypeScript, Vite, Tailwind CSS, Recharts, and Lucide icons.

## Features

- Dashboard layout with collapsible sidebar, sticky header, and main content
- Overview cards for orders, sales, customers, and products
- Revenue trend area chart and interactive pie/donut chart (category or payment mix)
- Recent orders table with search, status filters, and mobile cards
- Product performance, catalog, customers, and analytics views
- Global search plus page-level filters
- Notifications dropdown and user profile menu
- Responsive layout for desktop, tablet, and mobile with hover and enter animations

## Setup

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

```bash
npm run build
npm run preview
```

Demo data lives in `src/data/mockData.ts` so the UI is fully interactive without a backend.
